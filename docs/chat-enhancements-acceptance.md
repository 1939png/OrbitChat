# 聊天增强验收记录

用户确认：App直接联网检索；思考档位依模型能力，未知或不支持隐藏。

实现边界：搜索摘要作为外部参考，提供来源；消息原文入库，格式仅用于展示；手动上翻暂停追底，显式回底恢复。

验收项：
- 搜索关闭时无搜索请求；开启且配置缺失时提示；超时、取消与空结果明确处理。
- 已知模型使用真实参数，未知模型隐藏；档位按模型保存。
- 滑块蓝色到深紫色，向左粒子数量递增，离屏停帧。
- Unicode、分号、代码与未知公式保留；表格及常见公式可读。
- 流式更新、完成、取消不打断上翻阅读；回底按钮位于左下。
- 保留历史会话、API预设、启动动画与改名功能。

版本1.11（versionCode12）最终assembleDebug成功。主代理独立复验消息格式190项通过。网络模块独立能力识别/HTTPS/排队取消10项通过（子代理执行，主代理源码审查）。

搜索需配置启用JSON的SearXNG HTTPS端点；真实服务未实连。思考识别仅覆盖明确列出的官方模型，未知/兼容host隐藏；Anthropic为预算预设而非宣称原生离散档。公式为可读Unicode转换，复杂未知公式原样保留。

设备检查：adb devices -l 当前无连接设备。实机触摸、动画与IME验证待设备测试。
