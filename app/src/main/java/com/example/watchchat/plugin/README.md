# 插件 API / Plugin API\n\n插件 API 位于 com.example.watchchat.plugin，使用纯 Java 类型，适配当前无 AndroidX/Compose、Java、minSdk 26 工程。\n\n实现 ChatPlugin，提供不可变的 PluginMetadata，按需覆盖 onInstall/onStart/onStop，并返回 MessageHandler 或 ModelProvider。宿主创建 PluginRegistry，调用 register、startAll、dispatchMessage、stopAll。\n\n注册表按注册顺序保存插件，遍历时使用快照；生命周期、处理器和模型提供商访问逐插件捕获异常，并通过 PluginErrorHandler 报告，单个插件故障不会打断其它插件或主聊天流程。\n\nEchoPlugin 是最小示例：消息 /echo hello 返回 hello。插件层不依赖 Activity 或 ChatClient，因此现有调用保持不变。\n
